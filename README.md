# Creator Business Platform — Mini MVP

Веб-приложение для агентства инфлюенс-маркетинга. Заменяет таблицы и переписку
в WhatsApp: бизнес оставляет бриф → агентство подбирает креаторов из своей базы →
кампания идёт по статусам → клиент видит прогресс и получает отчёт.

Собрано по ТЗ «Creator Business Platform — Mini MVP» v1.0, объём — п.4 и п.5 общей концепции.
Без автосбора статистики и алгоритмического Creator Score: вся статистика вводится
руками агентством. Почему так и что с этим делать дальше — `docs/INSTAGRAM.md`.

## Стек

Next.js 16 (App Router, server actions) · React 19 · Tailwind 4 ·
Supabase (Postgres + Auth + Storage) · Vercel.

Схема БД — единственный источник правды по данным: `supabase/migrations/`.
Ролевая защита сделана на RLS в базе, а не только в интерфейсе.

## Роли

| Роль | Что может |
|---|---|
| **Admin** (агентство) | база креаторов, входящие брифы, подбор под кампанию, статусы, гонорары, отчёт |
| **Business** (клиент) | регистрация, бриф, просмотр предложенных креаторов, статус кампании, отчёт, витрина |

Клиент физически не видит внутренний тир и пометки агентства: таблица `creators`
закрыта для него на уровне RLS, наружу торчит вьюха `creator_public` только
с публичными полями.

## Воронка кампании

```
Новая заявка → Бриф согласован → Creators подобраны → Съёмка → Монтаж →
На согласовании у клиента → Опубликовано → Отчёт отправлен → Завершена
```

Каждая смена статуса пишется в `campaign_status_log` автоматически (триггер в БД) —
через пару месяцев это готовые данные для аналитики и будущего Creator Score.

## Быстрый старт

См. `docs/SETUP.md`. Кратко:

```bash
# 1. в Supabase выполнить supabase/migrations/0001_init.sql и 0002_rls.sql
# 2. cp .env.local.example .env.local и вписать ключи
npm install
npm run dev
```

Первый админ назначается в SQL — инструкция там же.

## Подключение Instagram

Схема и весь поток готовы, включаются переменными окружения. Пока `INSTAGRAM_APP_ID`
пуст, платформа живёт на ручном вводе и не показывает креатору лишних кнопок.

- `/connect/<token>` — персональная страница креатора с экраном согласия;
  ссылку агентство берёт в карточке креатора и отправляет в WhatsApp
- `/api/instagram/callback` — обмен кода на токен, шифрование, первая синхронизация
- `/api/meta/deauthorize`, `/api/meta/data-deletion` — обязательные колбэки Meta
- `/privacy`, `/terms`, `/data-deletion` — публичные страницы, которые читает ревьюер

Токены лежат в базе зашифрованными (AES-256-GCM, `TOKEN_ENCRYPTION_KEY`).
